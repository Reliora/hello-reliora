# Reliora — Site officiel

Site officiel de Reliora, plateforme d'accompagnement humain qui connecte les PME de l'Eurométropole de Strasbourg avec des développeurs juniors et en reconversion.

🌐 [hello-reliora.fr](https://hello-reliora.fr)

## À propos du projet

Reliora est une micro-entreprise immatriculée, opérée par un fondateur unique. La plateforme repose sur un modèle d'accompagnement humain plutôt qu'algorithmique : sélection manuelle des développeurs, médiation tout au long de la mission, paiement à la livraison.

## Stack technique

- **Front** : HTML5, CSS3, JavaScript vanilla
- **Hébergement** : GitHub Pages
- **Domaine** : OVH avec configuration DNS personnalisée
- **HTTPS** : Let's Encrypt (via enregistrements CAA)
- **Backend formulaires** : Google Apps Script + Google Sheets

## Fonctionnalités

- Landing page responsive avec sections modulaires
- Formulaire d'inscription multi-étapes (PME / Développeur)
- Soumission backend via Apps Script et stockage en Google Sheets
- Notifications par email à la réception d'une candidature
